写作台工具行那枚「分类」（去的是 /admin/categories，管分类：新建 / 改名 / 排序 / 删除）和报头、公开分类页的「分类」（/categories，读分类下的文章）是两个东西。 一个词指两件事，所以动词还给链接：写作台那枚改名「编辑分类」，公开分类页加一枚「编辑分类」通向同一个地方——入口与去处同名。

＊选定：入口落在标题旁（h2 之后，只给作者）；写作台改名与 h1 保持「分类」一并定。 下面三节是同一处设计的三种看法：作者登录后看到的完整版面、写作台那一行、以及读者看到什么（一个像素都不多）。

一、公开分类页——作者登录后看到的

改动只有标题旁那一枚：贴在 .archive-main 的现成写法上（「标题 + 一枚小字」的基线行，开发数据源下「示例内容」徽记占过的槽位）， 不占新行、不加新的线。形态是站里的安静链接 .link-quiet（印字印线），与写作台那枚同一个长相。

二、写作台工具行——那枚改名（同一份改动）

左侧那枚从「分类」改成「编辑分类」；右侧主操作「写新的一篇」不动。改完这一页上「分类」只指页面名，动词留给链接—— 两个去处也从此同名：这一枚和公开分类页那枚，写同一句话、去同一个地方。

按最近改动排

编辑分类 写新的一篇

写作页只有这一处叫「分类」。编辑台里那枚「去建一个分类」（一个分类都没有时的那句提示里）不动—— 那句话的场景是「你没有分类，去建一个」，换成「去编辑分类」反而绕。

落地要动的东西

  • AdminArticleListView.vue：工具行那枚 .link-quiet 的文字「分类」→「编辑分类」（L195，只改文字；那一行注释说的还是同一件事）。
  • CategoryListView.vue：.archive-main 里 h2 之后加那一枚—— <router-link v-if="isAuthor" class="link-quiet" :to="{ name: 'admin-categories' }">编辑分类</router-link>。 这一页要开始 import session——站里第一次在公开页里按登录身份分支；身份照 App.vue 的算法（session.account?.role === 'admin'）。 若嫌两处各算一遍，可把它收进 session.js 导出，App.vue 跟着改一行。
  • styles.css：零改动——.archive-main 本来就是「标题 + 一枚小字」的基线行，安静链接的样也是现成的。
  • 不动：写作-分类页的 h1（保持「分类」）、编辑台那枚「去建一个分类」、报头。
  • 另记（与本案无关的旧账）：App.vue L41 报头「写作」栏的 nav-here 漏了 'admin-categories' ——人在写作-分类页时报头不亮，一行可补。
