搜索框里点了一条浏览器记住的搜索历史，那一格就染上一层浅蓝，失焦也不散。那是浏览器自己 画的，不是站里的样式：Chromium / Edge / Safari 对被自动填充过的输入行都会铺这么一层 （#e8f0fe，这个值是从你那张截图上取样量出来的），在你改动这一格之前一直留着 ——它是在说「这个值是我替你填的」。下面两格把「长什么样」和「治了之后长什么样」摆在一起。

两格对照

左格是没治的搜索框，右格是治了之后的。都是真控件，可以点进去打字。

搜索框（平时）

为什么 background-color 治不住它

那条规则在浏览器自己的样式表里，优先级压过站里的样式——你在站里给这格写 background: #fff 也没用。治得住的是画在它上面的那一层：内阴影 （inset）画在底色之上、字之下，把整格铺满就把它盖住了。这一页里的「甲」那格就是 这么画的——底色一模一样，只是多了一条内阴影，眼睛看到的是白的。

两条规则——已落（2026-10-16），在 src/styles.css 里挨着 .search 那几条：

.search input:-webkit-autofill { box-shadow: 0 0 0 100px #fff inset; -webkit-text-fill-color: var(--ink); caret-color: var(--ink); }
.search input:autofill { box-shadow: 0 0 0 100px #fff inset; -webkit-text-fill-color: var(--ink); caret-color: var(--ink); }

第一条给 Chromium / WebKit——那层蓝就长在这两家（和那颗 ✕ 换皮是同一批浏览器，见 search-clear.html）；第二条是标准那一份，认它的浏览器也能吃到。-webkit-text-fill-color 收的是浏览器顺手改掉的字色（它那边是纯黑，站里是 --ink）——不写这一句，只有字色 差一点点，写了才是一个站里的一种墨。

100px 那一下是保险：内阴影的模糊半径 0、扩散铺满整格，多高多宽都盖得住，不必跟着输入框尺寸改。

选择器只写 .search input，不写裸的 input:-webkit-autofill：那会连 登录、注册、账号那几格的邮箱与口令一起治，把浏览器在凭据框上的那条提示也抹掉——那里那层 底色是有信息量的。要治的就是这两处搜索框（文章列表页、写作台列表页），它们共用 .search。

怎么手验

这一条探针验不了：自动填充要真有一份保存过的历史加上真的手势，无头浏览器造不出那个状态 （所以这一页里那层蓝是照你截图量出来的颜色画的，不是浏览器当场画的）。手工这一遍这样走：

  1. 在搜索框里打一个以前搜过的词，让下拉出来，从下拉里点一条——底色上来。
  2. 点空白处失焦：底色还在（这是浏览器自己的规矩，不是站里的问题）。
  3. 改动这一格（敲一个空格再删掉）：底色散去——浏览器就是靠「值被动过」来判断的。
  4. 改了样式之后重来一遍第 1 步：底色照旧由浏览器铺上，但眼睛看到的是白底、站里的墨字。
  5. 顺手看一眼登录页那几格：还是浏览器原来的样子（这一条只挑了 .search input）。
