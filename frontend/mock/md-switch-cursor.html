在「看预览」那枚字的中线上自上而下扫，每一像素问一次「这儿命中的是谁、它的 cursor 是什么」：

字上方 5.0px　→　div.md-switch　　pointer
那枚字本身　　→　label.link-quiet　default（箭头）
字下方 4.3px　→　div.md-switch　　pointer

这一行整高 25.9px，就是那枚字的行盒（字号 14px、行高 25.9px）；label 自己的盒子只有 16.6px——字 14px 加上它底下那条下划线（1px 的 border-bottom 与 .1rem 内边距），上下那 5.0px 与 4.3px 正是行盒比字盒多出来的两截 （5.0 + 16.6 + 4.3 = 25.9）。能点的只有 label 那一段，cursor 却写在外层盒子上，于是 「手」与「能点」正好对不上。把 cursor 挪到 label 上之后，手落在 537–553 这一段——正好是 那枚字的盒子，与能点的那一段重合。

落到产品里改哪几行

已落（2026-10-16）：src/styles.css 里 .md-switch 那条 去掉了 cursor: pointer，另起一条 .md-switch label { cursor: pointer; }。 与 .segmented label、.md-tools .upload-btn（也是 label）同一个写法： 站里别处都没有把 cursor 写在外层盒子上。

只挑 .md-switch label，不写宽泛的 label { cursor: pointer }：站里还有 别的 label（表单里的单选、复选那一族），它们该是箭头。字号、位置、点下去会发生什么，一个都 不动。
